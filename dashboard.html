Panduan Admin

Klik adalah web app reward: user menonton iklan untuk dapat koin, lalu menukar koin ke saldo DANA/OVO/GoPay/ShopeePay/pulsa.

  • Login wajib via Google.
  • Reward per iklan: 100 koin, batas 100 iklan/hari.
  • Check-in harian: 5–20 koin (sekali per hari).
  • Nilai tukar: 10.000 koin = Rp1.000.
  • Potongan konversi: 5% (user terima Rp950 dari Rp1.000).
  • Minimum tukar: 5.000 koin, kelipatan 5.000.
  • Koin kadaluarsa 30 hari tanpa login.

Alur: user menonton iklan → saldo koin bertambah (tabel balances) → user klik "Tukar ke DANA" → data masuk ke tabel payouts (status pending) → admin buka tab Payout → approve (transfer manual ke DANA user) atau reject (koin dikembalikan otomatis).

Tab User menampilkan semua user, total koin yang beredar, dan estimasi rupiah.

Tab Settings untuk edit konfigurasi (link iklan, reward, limit, dll).
